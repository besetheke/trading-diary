# AP-08 · UI

Maßgeblich ist §6, Abschnitt AP-08 in `plan/trading-journal-projektplan.md`
(Umfang: Dashboard, Positionsliste, Kampagnen- und Detailansicht, Kalender,
Journal-Editor, Korrektur-Dialoge).

## Konkretisierung

- React + Vite + Recharts; Frontend-Code unter `ui/`.
- Der Produktionsbuild wird von FastAPI als statische Dateien ausgeliefert
  (§3). Kein Node-Dev-Server während der Handelszeiten; Builds außerhalb.
- Jede Ansicht erreicht ihre Daten ausschließlich über die API (Abnahme) —
  kein direkter DB-Zugriff aus dem Frontend.
- Die Positionsliste nennt die Ebene **Positionen**, nicht Ketten; Einzeltrades
  ohne Roll erscheinen gleichrangig (E11).
- Korrektur-Dialoge schreiben ausschließlich Overrides und Klassifikationen,
  nie Rohdaten (Regel 4).
