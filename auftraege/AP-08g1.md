# AP-08g1 · Diagramme

Teil des Facelifts (`auftraege/AP-08f.md`, Abschnitt „Darstellung —
Entscheidung des Nutzers", D1–D3 lesen). Reine Oberfläche; die Daten liefert

**Erst nach AP-08f1 beginnen** (dieselben Formatierer, sauberer Stand).

## Zu bauen

### 1. Bausteine unter `ui/src/diagramm/`

Eigene SVG-Komponenten, **keine neue Abhängigkeit** (D1):

- `Linie.tsx` — Props `punkte: { x: string; y: string }[]` (x = ISO-Datum,
  y = Betrag als Text der API), optional `titel`. Verbundene Linie über
  der Zeit.
- `Flaeche.tsx` — wie `Linie`, aber Fläche zwischen Linie und Nulllinie;
  für den Drawdown (Werte ≤ 0) rot gefüllt.
- `Balken.tsx` — Props `balken: { x: string; y: string }[]` (x = Beschriftung,
  z. B. `2025-03`), ein Balken je Eintrag, positiv grün, negativ rot (Farben
  wie `.positiv`/`.negativ` in `stil.css`).

Gemeinsam für alle drei:

- **Responsiv:** `viewBox` + `width: 100%`; feste Höhe (etwa 220 px Linie/
  Fläche, 180 px Balken).
- **Achsen:** y mit 4–6 runden Teilstrichen, beschriftet über `betrag()`
  (Tausenderpunkt, Komma); Nulllinie deutlich, wenn 0 im Bereich liegt.
  x mit Monats- oder Jahresmarken je nach Spanne (bis ~18 Monate: Monate
  `MM/JJ`, darüber Jahre).
- **Zeiger:** Beim Überfahren eine senkrechte Hilfslinie am nächsten Punkt
  und ein Kasten mit Datum (`datumDe()`) und Betrag (`geldDe()`, Text der API,
  unverändert) — Tastatur nicht nötig.
- **Leer:** ohne Punkte ein Hinweis statt eines leeren Rahmens.
- **D2:** Für Pixelpositionen darf `Number(y)` verwendet werden — sonst
  nirgends. Angezeigt werden ausschließlich die Texte der API über die
  Formatierer. Diese Ausnahme im Kopfkommentar der Bausteine begründen.
- Viele Punkte (Gesamthistorie ~1.000 Tage) müssen flüssig bleiben: eine
  `<path>`-Linie, keine `<circle>` je Punkt.

### 2. Dashboard (`ui/src/Dashboard.tsx`)

Oberhalb der bestehenden Tabellen (D3: Tabellen bleiben):

1. **Equity-Linie** aus `tage[].kumuliert_eur`.
2. **Drawdown-Fläche** aus `tage[].drawdown_eur`.
3. **Monatsbalken** aus `monate[].summe_netto_eur`.

Der gewählte Zeitraum (Kopf) wirkt bereits; die Diagramme folgen ihm, weil
sie dieselben Daten nutzen.

### 3. `stil.css`

Den Kopfkommentar „kein Diagramm" an D1–D3 anpassen; Stile für die
Diagramme ergänzen.
